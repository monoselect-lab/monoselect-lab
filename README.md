## モノセレクトラボ

在宅ワーク × 賃貸・ワンルームの「困りごと」を起点に、商品の比較と選び方を書いています。

サイト → **https://monoselect-lab.github.io/**

editorial な立場でやっていること:

- 製品カテゴリからではなく、**症状から入る**。「Wi-Fiが遅い」ではなく「速度テストは速いのにWeb会議だけ固まる」。
- **買わずに済む手を先に書く**。0円で試せる切り分けを product セクションより前に置いています。
- **すすめなかった手**を毎回明記する。候補に挙げて落とした製品と、その理由を残します。
- 実測レポートではなく**調査記事**であることを各記事の冒頭で明示。星は編集部評価で、Amazonの評価そのものではありません。
